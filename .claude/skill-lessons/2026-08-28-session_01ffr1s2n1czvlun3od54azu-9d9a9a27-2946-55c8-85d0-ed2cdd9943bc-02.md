# .claude/skills/repos/SKILL.md — reading a percona/pmm or percona/grafana PR diff from a pmm-qa-only session

- Added: 2026-08-28
- Applies to: .claude/skills/repos/SKILL.md and .claude/skills/git-diff/SKILL.md
- Evidence: `pull_request_read` and `gh api repos/percona/grafana/pulls/921` both returned "not configured for this session / Allowed repositories: percona/pmm-qa"; `add_repo` answered `read_available` (anonymous git only, nothing attached) and `add_repo access:"push"` was refused as a cross-tier add. `git fetch --depth 1 origin refs/pull/921/head` then produced a `git show --stat` listing the entire tree because the shallow ref has no parent; `--depth 2` gave the real 10-file diff.
- Proposed change: document the fallback for an unattached percona repo — anonymous `git clone --depth 1 --filter=blob:none --no-checkout`, then `git fetch --depth 2 origin refs/pull/<N>/head:pr<N>` and `git show pr<N>` — and note that `--depth 1` yields a whole-tree diff, and that merge-state checks need `git fetch --depth 50 origin main` plus `git merge-base --is-ancestor`.
