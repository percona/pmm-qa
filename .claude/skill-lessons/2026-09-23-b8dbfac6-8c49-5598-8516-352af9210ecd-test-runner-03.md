# .claude/skills/linode-ha-provisioning/SKILL.md — per-pod Raft leader probe that needs no admin credentials

- Added: 2026-09-23
- Applies to: target only
- Evidence: While admin API calls returned 401, `kubectl exec deploy/pmm-ha-haproxy -- wget -S -q -O /dev/null --no-check-certificate https://<podIP>:8443/v1/server/leaderHealthCheck` gave 200 on the leader and 400 on followers, matching `/v1/ha/nodes` later; an `awk '{print $2}'` parse printed `server` from wget's `server returned error: HTTP/1.1 400` line, fixed with `grep -o 'HTTP/[0-9.]* [0-9]*'`.
- Proposed change: Add this probe (with the grep parse) to "Verify HA behaviour" as the credential-free way to confirm exactly one leader per pod.
