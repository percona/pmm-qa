# .claude/skills/linode-docker-provisioning/SKILL.md — `--pmm-server-ip pmm-server` forces port 443 and cannot reach the step-2 server

- Added: 2026-09-15
- Applies to: .claude/skills/linode-docker-provisioning/SKILL.md
- Evidence: Step 3 instructs `--pmm-server-ip pmm-server`; `lib/docker.sh:resolve_pmm_server()` hardcodes `PMM_SERVER_PORT=443` for that flag, while step 2's own `docker run` publishes the server on 8443, so a `--database psmdb` setup built every image and then died with `Failed to register pmm-agent on PMM Server: Post "https://pmm-server:443/v1/management/nodes": connect: connection refused`.
- Proposed change: For a PMM Server started by step 2 on the same box, omit `--pmm-server-ip` so `discover_pmm_server()` resolves host=`pmm-server` port=8443; reserve `--pmm-server-ip` for a genuinely external server listening on 443.
