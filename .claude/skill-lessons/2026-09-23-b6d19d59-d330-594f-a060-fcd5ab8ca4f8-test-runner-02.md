# .claude/skills/add-ha-test/SKILL.md — scratch-config executablePath must be set per project

- Added: 2026-09-23
- Applies to: .claude/skills/add-ha-test/SKILL.md
- Evidence: A scratch config setting `use.launchOptions.executablePath` at top level was ignored because `playwright.config.ts` defines `launchOptions` inside `projects[0].use`, so all 11 tests failed with `Executable doesn't exist at /opt/pw-browsers/chromium_headless_shell-1234/...`; mapping `projects[].use.launchOptions.executablePath` fixed it.
- Proposed change: In the cloud-session override note, state that `executablePath` goes on each `projects[].use.launchOptions` (spread the base project), with a three-line snippet.
