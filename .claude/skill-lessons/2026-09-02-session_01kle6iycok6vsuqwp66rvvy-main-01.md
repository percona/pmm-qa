# .claude/skills/ui-evidence/SKILL.md — a hand-rolled Playwright script needs the helpers' launch options and must exclude the /pmm-ui/ shell frame

- Added: 2026-09-02
- Applies to: target only
- Evidence: Driving the Add-remote-PostgreSQL form to capture the outbound `POST /v1/management/services` body is beyond what the three helper scripts do, so a script was written from scratch. A bare `chromium.launch({ args })` died with `Executable doesn't exist at /opt/pw-browsers/chromium_headless_shell-1234/...` because the freshly `npm install`-ed playwright resolves a browser revision that is not present; `pmm-ui-login.js:96` already solves this with `executablePath: "/opt/pw-browsers/chromium"` plus `proxyLaunchOptions({ spkiPins })` from `.claude/scripts/lib/proxy.js`. Two further 60s `waitForSelector` timeouts followed because `/graph/add-instance` now redirects to `/pmm-ui/graph/add-instance` and renders the old Grafana page in an iframe, so `page.frames().find(f => f.url().includes('/graph/add-instance'))` matches the outer shell frame, whose URL contains that substring too.
- Proposed change: Add a short "writing your own Playwright script" note to the skill: reuse `executablePath: "/opt/pw-browsers/chromium"` and `proxyLaunchOptions({ spkiPins })` rather than a bare `chromium.launch`, and when selecting the PMM page frame require the URL to contain `/graph/` while excluding `/pmm-ui/`.
