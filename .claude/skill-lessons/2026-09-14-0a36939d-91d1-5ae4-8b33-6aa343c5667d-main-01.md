# .claude/agents/investigator.md — rule a diff out of an erratic-duration investigation by comparing runs of the same commit

- Added: 2026-09-14
- Applies to: .claude/agents/investigator.md
- Evidence: Asked why pmm-framework setup takes 8 min sometimes and 50 min other times, the session theorised about playbook content and shipped a container-apt change that did not help. Three dispatches of one workflow on the same commit, 6 minutes apart, then showed the same matrix spec at 5m16 / 33m56 / 20m06 and another at 4m37 / 4m42 / 23m05 — identical code, so the variance was never in the diff. The per-step durations came from one `actions/runs/<id>/jobs` call, before any log was read.
- Proposed change: In the investigation steps, add that an *erratic duration* report (not a deterministic failure) starts by comparing per-unit step durations across two or more runs of the **same commit** — `actions/runs/<id>/jobs`, `.jobs[].steps[]` `started_at`/`completed_at` — before reading logs or forming a code-level theory; a unit that varies several-fold across same-commit runs is environmental contention, so stop patching code and identify the shared resource instead.
