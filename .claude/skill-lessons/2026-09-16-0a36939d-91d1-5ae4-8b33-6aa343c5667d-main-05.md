# .claude/skills/pmm-framework-change/SKILL.md — an Ansible shell task runs in the playbook's directory, not the pmm_qa root

- Added: 2026-09-16
- Applies to: .claude/skills/pmm-framework-change/SKILL.md
- Evidence: A task file included from many playbooks invoked a helper as `./scripts/<name>.sh`. It resolved for the root-level playbooks and failed with `not found` (rc 127) for one in a subdirectory, killing the whole setup. The repo already shows the rule: `tls-ssl-setup/mysql_tls_setup.yml` reaches `./mysql/mysql_ssl_setup.sh`, a file one level below the playbook, not below the root.
- Proposed change: Add a verification step — a shell task added to a file under `qa-integration/pmm_qa/` must address other repo files absolutely (via the exported `PMM_QA_ROOT`), and any relative path in a shared task file must be checked against a playbook in a subdirectory, not only a root-level one.
