# CLAUDE.md — reach for the helper the file already has before writing a new one

- Added: 2026-09-18
- Applies to: all skills that write code
- Evidence: a fix added a 30-line bespoke scroller to a page object whose existing `collectTextsAcrossScroll` already scrolled the whole dashboard; the user rejected it ("ficou tão grande, verboso... temos o loadAllPanels que supostamente faz isso, nao?") and reusing the existing helper made the block smaller than the code it replaced. The same session had already drawn a correction for extracting a single-use helper.
- Proposed change: add to House style — before adding a function, grep the file for one that already does the work, and prefer calling it again over a new private helper; a fix that grows the file is a signal the wrong shape was chosen.
