# .claude/skills/repos/SKILL.md — `list_workflow_runs` carries full squashed commit bodies and needs a `fields` filter

- Added: 2026-09-15
- Applies to: .claude/skills/repos/SKILL.md
- Evidence: `actions_list` → `list_workflow_runs` on pmm-qa returned each run's whole `head_commit.message`; a 15-run page spilled to a file at 132 KB and a 5-run page cost roughly 15k result tokens, all of it squashed PR commit bodies rather than run state.
- Proposed change: In the GitHub MCP section, state that `list_workflow_runs` needs `fields` limited to id/created_at/status/conclusion/run_number/head_sha whenever the question is which runs failed and when.
