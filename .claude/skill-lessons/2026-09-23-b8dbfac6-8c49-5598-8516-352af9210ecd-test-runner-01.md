# .claude/skills/linode-ha-provisioning/SKILL.md — relay `chart_version` pins both charts, whose version lines differ

- Added: 2026-09-23
- Applies to: target only
- Evidence: Provisioning with `chart_version:"1.6.1"` created the LKE cluster, then failed with `chart "pmm-ha-dependencies" matching 1.6.1 not found` (deps line is 1.0.0), costing a teardown and a second 20-minute build.
- Proposed change: In "Testing the released chart", state that `chart_version` applies to both charts, so a pin must exist for both (`helm search repo` each first) or be left unset when latest `pmm-ha` is the target.
