# .claude/skills/repos/SKILL.md — percona/pmm's default branch is `main`; `v3` is the pmm-submodules base, not pmm's

- Added: 2026-09-22
- Applies to: target only
- Evidence: Investigating an FB failure from a pmm-submodules PR whose base branch is `v3`, that ref was carried over to the product repo: `git fetch origin v3` returned `fatal: couldn't find remote ref v3` and `gh api "repos/percona/pmm/commits?sha=v3&path=..."` returned 404 Not Found, which reads as a missing file rather than a missing branch. `gh api repos/percona/pmm --jq .default_branch` answers `main`.
- Proposed change: In the "Product & QA" repo table or the pmm-submodules note, state that `v3` is the base branch inside `Percona-Lab/pmm-submodules` only and that `percona/pmm`'s default branch is `main`, so a ref must not be carried across repos; a 404 from a `?sha=<ref>` path means the ref, not the file.
