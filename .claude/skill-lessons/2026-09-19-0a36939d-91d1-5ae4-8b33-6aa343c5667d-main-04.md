# .claude/agents/investigator.md — a parameterised test row examines one subject, so its trace cannot show which subjects are unaffected

- Added: 2026-09-19
- Applies to: .claude/agents/investigator.md
- Evidence: a trace showing 90 empty panels all naming one service was read as "only this service lost its metrics, the other two are fine"; that test row was parameterised on a single service, so the others were never examined and the contrast was an artifact of sampling.
- Proposed change: before claiming a subject is unaffected, confirm the evidence actually exercised it — a per-subject parameterised run only supports claims about the subject that row selected.
