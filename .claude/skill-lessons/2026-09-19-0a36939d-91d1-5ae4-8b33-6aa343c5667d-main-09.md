# .claude/skills/jenkins-builds/SKILL.md — Artifact tools reject relative_paths containing + or @

- Added: 2026-09-19
- Applies to: .claude/skills/jenkins-builds/SKILL.md
- Evidence: `export_build_artifact` refused a failed-test screenshot with "relative_path has invalid characters"; CodeceptJS names every `.failed.png` after the scenario title, so `+` and `@` appear in the path of essentially all of them.
- Proposed change: Note that `export_build_artifact` / `get_build_artifact` accept only a restricted character set in `relative_path`, so per-test screenshots archived under their scenario names are unreachable by path — reach a build's artifacts through the archived tarballs (`list_archive_artifact` / `extract_archive_artifact`) instead.
