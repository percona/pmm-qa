# CLAUDE.md — Brace a variable before a colon in zsh: `${ref}:path`, never `$ref:path`

- Added: 2026-09-24
- Applies to: all sessions (the Bash tool runs zsh on macOS hosts)
- Evidence: `git show $ref:charts/pmm-ha/Chart.yaml` in a loop expanded to `origin/mainharts/...` because zsh read `:c` as a history modifier, and every read failed until the variable was braced as `${ref}:charts/...`.
- Proposed change: Add a House style rule: when a variable is followed by `:` (git `<rev>:<path>`, `host:port`), write `${var}:…` so zsh modifiers (`:h`, `:t`, `:r`, `:e`, `:c`, `:a`) cannot consume the next character.
