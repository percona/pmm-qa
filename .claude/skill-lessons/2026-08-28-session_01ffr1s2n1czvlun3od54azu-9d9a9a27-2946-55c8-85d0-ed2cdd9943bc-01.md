# .claude/skills/linode-docker-provisioning/SKILL.md — run.sh fails on large remote command OUTPUT, not just long commands

- Added: 2026-08-28
- Applies to: target only
- Evidence: `run.sh <run_id> -- "docker exec pmm-server curl -sS http://mailhog:8025/api/v2/messages"` (~500 KB of JSON) aborted with `run.sh: line 71: /usr/local/bin/python3: Argument list too long`; the same command re-run so the box parsed the JSON and printed a ~10-line summary succeeded, as did returning files as `tar czf - … | base64 -w0` (~8 KB).
- Proposed change: add a note to the "Accessing the VM" section that `run.sh` passes the remote output through a local `python3` argv and so cannot return large payloads — do the parsing on the box and return a small summary, or transfer files as gzip+base64.
