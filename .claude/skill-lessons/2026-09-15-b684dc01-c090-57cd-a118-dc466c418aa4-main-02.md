# .claude/skills/linode-docker-provisioning/SKILL.md — the VM has no Node, so any e2e suite run on it needs Node installed first

- Added: 2026-09-15
- Applies to: .claude/skills/linode-docker-provisioning/SKILL.md
- Evidence: cloud-init installs Docker and Ansible only; two detached jobs that ran `npm ci` / `npx playwright install chromium` in `e2e_tests` exited 127 with `npx: command not found`, and because they were detached the failure surfaced only at the DONE_MARKER sentinel, not at launch.
- Proposed change: Add a step before running `e2e_tests`/`codeceptjs-e2e` on the box that installs Node (`curl -fsSL https://deb.nodesource.com/setup_22.x | bash - && apt-get install -y nodejs`) and verifies `node -v` in the same call.
