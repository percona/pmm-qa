# .claude/skills/pmm-framework-change/SKILL.md — PR-check e2e legs do not exercise the repo-component client install

- Added: 2026-09-16
- Applies to: .claude/skills/pmm-framework-change/SKILL.md
- Evidence: A change to the pmm-client install path passed every PR-check e2e leg twice and then broke the first nightly setup job that ran. Those legs pass `pmm_client_version: latest-tarball`, which leaves the repository component empty and skips the changed block entirely; only a run with a component version (`3-dev-latest`, `pmm3-rc`, `pmm3-latest`) reaches it.
- Proposed change: Record that a green PR-check e2e run is not evidence for a change on the component install path, and require exercising it another way (a dispatched nightly, or a VM run with a component `client_version`) before calling such a change verified.
