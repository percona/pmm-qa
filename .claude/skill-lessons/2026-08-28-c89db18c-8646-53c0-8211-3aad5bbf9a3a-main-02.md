# .claude/skills/linode-ha-provisioning/SKILL.md — check the chart branch's version before swapping it in, or the default swap downgrades PMM

- Added: 2026-08-28
- Applies to: target only
- Evidence: The skill instructs swapping the relay-installed released chart for the `PMM-HA-GA` branch on every HA run because that branch "is not merged or published yet", but the branch's `charts/pmm-ha/Chart.yaml` is version 1.6.0 / appVersion 3.9.0 while the relay installed the published 1.6.1 / appVersion 3.9.1 — the swap would have downgraded both chart and PMM server on a run with no chart change under test.
- Proposed change: In "Charts — first decide", require reading `Chart.yaml` version/appVersion on the branch and comparing it with the installed release (`helm list -n pmm`) before swapping, and state that the swap applies when the branch carries the change under test or is newer, not unconditionally.
