# .claude/skills/qa-code-review/SKILL.md — a behaviour-preserving suggestion must not carry forward behaviour an open thread has already faulted

- Added: 2026-09-14
- Applies to: .claude/skills/qa-code-review/SKILL.md
- Evidence: The review proposed collapsing a `case` into a single `if` and deliberately kept the `http.*` alternative "so the guard still mirrors the `== http*` branch at line 134" — minutes after another reviewer's thread on the same file had shown that glob accepts `http-invalid` and `httpfoo`. The author adopted the restructuring but replaced the alternative with `https?://.*`, citing that thread (https://github.com/percona/pmm-qa/pull/1429#discussion_r4006770106).
- Proposed change: Add to check 9 that where a suggestion is justified as preserving existing behaviour, the preserved behaviour is first checked against the PR's open threads — a refactor that re-encodes a defect another reviewer has already raised is wrong in its content even when the restructuring is right.
