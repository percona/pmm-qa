# .claude/agents/investigator.md — read the failing test names from the run-logs zip of the trigger run and its predecessors together

- Added: 2026-09-15
- Applies to: .claude/agents/investigator.md
- Evidence: `get_job_logs failed_only` named three failed nightly jobs but no test; downloading and grepping each run's logs zip locally cost zero result tokens and, done for the trigger run plus the two preceding nightlies, showed both which failures were new that night and that the job's own `tags_for_tests` had changed between them — which was the root cause.
- Proposed change: In the CI-trigger step, direct that the run-logs zips for the trigger run and its immediate predecessors be fetched in one batch and grepped locally for the `test execution` files, before any per-run jobs listing.
