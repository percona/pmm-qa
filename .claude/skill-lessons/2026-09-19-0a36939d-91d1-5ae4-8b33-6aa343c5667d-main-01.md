# .claude/skills/linode-docker-provisioning/SKILL.md — Grafana's login lockout presents as an element-not-found timeout, not an auth error

- Added: 2026-09-19
- Applies to: .claude/skills/linode-docker-provisioning/SKILL.md, and .claude/skills/ui-evidence/SKILL.md where it drives an authenticated PMM page
- Evidence: after several rapid logins, four consecutive suite runs failed with "element (#grafana-iframe) still not visible after 60 sec"; the cause was diagnosed as a TLS setting, then as an empty password, before one login POST returned 401 and named the lockout — and a 7-minute stand-off did not clear it because logins kept being issued during it.
- Proposed change: in the lockout paragraph, state that the lockout surfaces downstream as a missing element or navigation timeout because the app never leaves the login page, that the first check on any auth-dependent UI failure is a single login status code rather than a re-run or a new hypothesis, and that a stand-off only counts when no auth request is issued during it.
