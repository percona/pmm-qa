# .claude/agents/investigator.md — a fix for a CI failure you cannot reproduce ships as "unverified", never as "fixed"

- Added: 2026-09-18
- Applies to: all skills that push fixes for CI failures
- Evidence: two commits in one session were reported as fixes and were inert — one wrapped a CodeceptJS `I.waitForElement` in try/catch (the recorder rejects the test, not the catch), the other swapped an `@checked` XPath for `:checked` when the real cause was that the surrounding list is virtualised; both were only exposed by the next nightly run failing identically.
- Proposed change: when a fix cannot be exercised locally, require the commit or report to name the observable that would confirm it (the exact test and the run that will re-exercise it) and to call the fix unverified until that run lands.
