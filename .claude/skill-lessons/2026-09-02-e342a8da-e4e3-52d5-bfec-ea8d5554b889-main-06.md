# .claude/agents/pr-maintainer.md — do not spend the shared CodeRabbit quota refreshing a stale verdict

- Added: 2026-09-02
- Applies to: any agent driving a percona/pmm-qa PR through CodeRabbit review
- Evidence: A PR's summary comment kept a `Merge Risk: Moderate · up to <older sha>` banner after its findings were fixed, because the bot's review-limit reset landed before it could re-score the new head. An `@coderabbitai review` comment was posted to refresh it and came back `⚠️ Action not completed — Review rate limited` ("Next included review available in 13 minutes"), leaving the banner unchanged. Both reasons it would fail were visible in advance: the limit notice was already on the PR, and CodeRabbit's own reply text states it "does not re-review already reviewed commits" -- and that head had already been reviewed, which is where its own per-thread "✅ Addressed in commit <sha>" markers came from.
- Proposed change: When a CodeRabbit summary or risk verdict is stale relative to the head, correct the record with one short comment stating the current facts rather than requesting a re-review; the OSS review allowance is a shared org resource, and a re-review of an already-reviewed commit does not refresh the verdict anyway.
