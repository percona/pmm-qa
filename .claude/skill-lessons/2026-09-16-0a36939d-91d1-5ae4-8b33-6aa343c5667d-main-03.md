# .claude/agents/investigator.md — prove a failure is deterministic before saying so, not only that it is a flake

- Added: 2026-09-16
- Applies to: .claude/agents/investigator.md
- Evidence: A commit message asserted "It is not a flake" about a red e2e job; the immediately preceding run of the same branch, on the same images, had passed that same job, so the claim was wrong and needed a correction commit. The agent file tells you to re-run before calling something flaky, but says nothing about the opposite claim.
- Proposed change: Extend the re-run rule so both directions need evidence — before calling a failure deterministic or "not a flake", list the branch's recent runs and check whether the same job passed on the preceding commit; if it did, treat it as intermittent and fix the race, not only the defect.
