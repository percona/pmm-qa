# .claude/agents/investigator.md — a prior FB triage comment is a stop condition only once its linked fix is shown not to have landed

- Added: 2026-09-11
- Applies to: target only
- Evidence: Dedup step 1 tells the FB source to stop when a prior Investigator triage comment on the submodules PR names "the same failing tests, still accurate". PR #4449 carried exactly such a comment (2026-09-02) naming `ruleTemplates_test.js` and fix PR percona/pmm-qa#1297, and stopping there would have been wrong: #1297 merged 2026-09-03, run 34601581070 used pmm-qa `main` @4d5e842 which contains it, that check was green, and the two red checks that day (`helm-tests`, `@pmm-ps-integration`) were unrelated to the comment. "Still accurate" is the whole load-bearing test and the skill gives no way to evaluate it.
- Proposed change: In dedup step 1's FB-source paragraph, make "still accurate" mechanical — before stopping, read the merged state of any fix PR the comment links and compare the comment's failing check names against the current run's; a merged fix, or a different set of red checks, means the comment is stale and the investigation continues.
