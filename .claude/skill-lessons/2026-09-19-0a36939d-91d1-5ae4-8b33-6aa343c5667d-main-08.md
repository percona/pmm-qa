# .claude/skills/jenkins-builds/SKILL.md — Read the server's own grafana.log before a failed test's screenshot or trace

- Added: 2026-09-19
- Applies to: .claude/skills/jenkins-builds/SKILL.md
- Evidence: Five consecutive CodeceptJS tests failed with "#grafana-iframe still not visible after 60 sec"; extracting srv-logs/grafana.log from the build's srv-logs.tar.gz and grepping `level=error` plus `path=<x> status=<code>` around the failure window named the cause verbatim in two calls — five `[password-auth.invalid] invalid password` attempts in one second followed by "too many consecutive incorrect login attempts for user - login for user temporarily blocked", expiring exactly when the suite went green again.
- Proposed change: When a PMM UI test fails on a missing element, an unexplained 401, or a page that renders as login, extract `srv-logs/grafana.log` from the build's `srv-logs.tar.gz` with `extract_archive_artifact` and grep it bounded to the failure window before reaching for the screenshot or Playwright trace.
