# .claude/skills/linode-docker-provisioning/SKILL.md — Playwright's request fixture ignores the sandbox proxy, so repo e2e tests 503 against the VM

- Added: 2026-08-28
- Applies to: target only
- Evidence: `npx playwright test` from `e2e_tests/` against the run's `<ip>.nip.io` PMM returned HTTP 503 "upstream connect error or disconnect/reset before headers" on every request, while `curl` to the same URL returned 200; a `request.newContext({proxy:{server:<the session's HTTPS_PROXY>}})` probe returned 200, confirming Playwright's APIRequestContext does not read the proxy env vars that `curl` honours.
- Proposed change: in the UI/testing step, note that running the repo's Playwright suite against the VM from this environment needs a scratch config extending `playwright.config.ts` with `use.proxy` set to the session's `HTTPS_PROXY` (CI runners have direct egress and need no such override), and that the scratch config must not be committed.
