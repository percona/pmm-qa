# .claude/skills/repos/SKILL.md — the CCR review-threads route names fields differently from GraphQL, and a wrong jq path reads as data

- Added: 2026-09-21
- Applies to: .claude/skills/repos/SKILL.md
- Evidence: GraphQL is refused in these sessions and the error names the replacement route, `GET /repos/{o}/{r}/pulls/{n}/ccr/review_threads`. Queried with the GraphQL-style `.is_resolved`, it returned seven rows of `resolved=null` — indistinguishable from seven genuinely unresolved threads on a PR that had none. The actual keys are `comment_ids`, `line`, `outdated`, `path`, `resolved`.
- Proposed change: Record the CCR routes (review_threads, comments/{id}/resolve, auto_merge, ready_for_review, convert_to_draft) as the GraphQL replacement, with review_threads' real field names, and note that a uniform null column means a wrong jq path — check `.[0] | keys` before reading a zero or a null as an answer.
