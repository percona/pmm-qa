# .claude/skills/fb-tests/SKILL.md — the empty-subset check keys on a step name only the Playwright runners use

- Added: 2026-09-21
- Applies to: .claude/skills/fb-tests/SKILL.md
- Evidence: The skill says a green e2e job counts as a pass only if its "Execute e2e tests" step concluded success. In pmm-submodules run 35602792321 the CodeceptJS jobs (@rta, @user-password) name that step `Run UI tests: @<tag> with launchable` and the podman job `Execute e2e tests with tags @<tag>`, so a check matching the documented name reported two jobs that had run and passed their tests as having run none. The same runs also finished in 8.5-12.5 minutes, below the skill's "real runs take 15-19.5 minutes" figure.
- Proposed change: Key the empty-subset check on the runner-independent `Skip notice` step in the same payload (`skipped` = subset was not empty, tests ran; `success` = the job skipped everything), note that the test step's name varies by runner, and drop duration as a proxy for it.
