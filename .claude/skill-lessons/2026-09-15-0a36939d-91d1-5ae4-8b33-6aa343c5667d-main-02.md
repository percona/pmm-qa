# .claude/skills/linode-docker-provisioning/SKILL.md — a watch that must outlive the turn cannot run in the session sandbox

- Added: 2026-09-15
- Applies to: any skill or agent that proposes long-running background measurement
- Evidence: A sampler, watcher and supervisor started with nohup ran fine while the session was woken every 30 min, then died within ~3 min of switching to 1 h wakeups, losing six publish windows overnight; restarted the next day they died again within ~10 min, taking dockerd and the built image with them. Only the scratchpad disk survived. A supervisor that restarts dead children was written and verified, and still did not help, because the whole container goes.
- Proposed change: State that background processes in the session sandbox do not outlive the turn — the container is reclaimed between turns and takes daemons, dockerd and docker images with it, while the scratchpad disk persists — so continuous measurement must either run inside each turn with state in files, or be moved to a throwaway Linode VM; never promise an unattended overnight watch from the session container.
