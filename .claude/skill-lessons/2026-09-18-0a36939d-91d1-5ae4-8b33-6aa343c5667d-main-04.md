# .claude/agents/investigator.md — Playwright HTML-reporter trace zips name the network log per browser context

- Added: 2026-09-18
- Applies to: target only
- Evidence: The trace guidance names `trace.network`, which is correct for a CodeceptJS `output/trace/*.failed.zip`, but a zip from the Playwright HTML reporter (`playwright-report/data/*.zip`) contains `0-trace.network` / `1-trace.network`, one per browser context. A first parse failed on the bare name before the glob was widened.
- Proposed change: In the trace paragraph, note both spellings and instruct globbing `*-trace.network` alongside the bare `trace.network`.
