# .claude/hooks/skill-gardener-review.sh — the observer reminder fires only at turn start, so capture is silently skipped

- Added: 2026-08-25
- Evidence: The gardener's wiring was verified end to end and is sound — `UserPromptSubmit` and `SubagentStart` are both valid hook events in Claude Code 2.1.245, both accept `additionalContext`, the script emits the correct JSON for each and exits 0 on `SKILL_GARDENER=off`, malformed input and unhandled events, and `.claude/skill-lessons/**` is un-ignored in `.gitignore`. Despite that, `origin` carried no `skill-gardener/*` branch and `main` carried no `.claude/skill-lessons/` directory at all: across every session since the hook landed, zero entries were ever captured.
- Proposed change: the reminder's only delivery point is the start of the turn, before any evidence exists, and nothing re-raises it once the work that would furnish a lesson has happened — so add a `Stop` (and `SubagentStop`) hook entry that re-injects the one-line observer reminder at end of turn, keeping the existing turn-start injection as the priming half. This stays within the skill's "no extra stop-time LLM pass" constraint: it appends context to a call the harness already makes rather than starting a new audit pass.
