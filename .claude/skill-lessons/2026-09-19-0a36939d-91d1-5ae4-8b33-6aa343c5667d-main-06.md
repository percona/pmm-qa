# .claude/skills/jenkins-builds/SKILL.md — aborting a build that provisions cloud infrastructure leaks it, because teardown lives in its post actions

- Added: 2026-09-19
- Applies to: .claude/skills/jenkins-builds/SKILL.md
- Evidence: mass-stopping an orchestrator's children left four live clusters with 6-7 AWS resource types each and no saved state, each traceable to an aborted build number; a cluster listing reported four found via AWS resource discovery before the sweep and zero after.
- Proposed change: say that stopping builds which create cloud resources must be followed immediately by a list-then-destroy sweep, and that the leak is named before aborting rather than discovered afterwards.
