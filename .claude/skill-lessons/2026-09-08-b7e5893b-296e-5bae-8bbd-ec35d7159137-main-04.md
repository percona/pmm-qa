# .claude/agents/investigator.md — read a component's own README/ARCHITECTURE before changing its behaviour, not only its code

- Added: 2026-09-08
- Applies to: .claude/agents/investigator.md
- Evidence: A fix made single-spec `--parallel` runs stream instead of buffering; review showed the same directory's `ARCHITECTURE.md` states the CI runners deliberately omit `--verbose` "so day-to-day runs stay quiet", which the change silently inverted for fourteen nightly setup shards, and that `README.md` documented the old behaviour in three places. The change was then dropped as both contrary to design intent and redundant.
- Proposed change: In the fix step, require reading any `README.md`/`ARCHITECTURE.md` alongside the file being changed before altering observable behaviour — they may state the property the fix would invert, and any surviving behaviour change has to be reflected there in the same PR.
