# .claude/agents/investigator.md — a shared code path is not a shared cause; the discriminator is the data each caller feeds it

- Added: 2026-09-19
- Applies to: .claude/agents/investigator.md
- Evidence: a regression was blamed on a new variable, then wrongly ruled out because two sibling playbooks take the identical change and stay green; the real discriminator was that only the failing one's container name contained a dot, which Grafana regex-escapes in an exact-match query.
- Proposed change: when a suspect change is shared by passing and failing callers, compare the concrete values each caller produces before ruling the change out, and state that comparison as the reason.
