# .claude/agents/investigator.md — a locator probe must replay the page object's setup, and carry a locator known to match

- Added: 2026-09-21
- Applies to: target only
- Evidence: A probe driving the shipped `timeSeries.component.ts` locator against a live Grafana dashboard reported `section=0` for every panel, including ones known unaffected, because it navigated and scrolled but never expanded the collapsed rows that `dashboards.page.ts:loadAllPanels()` opens via `getByLabel('Expand row')`. That reading is indistinguishable from the defect under investigation. After adding row expansion the same probe returned 0 for the three affected panels and 1 for every other, which was the actual measurement.
- Proposed change: Extend step 4's locator-measurement guidance to require that a probe replay the page object's own setup steps (row expansion, `loadAllPanels()`), not just its locator, and that it always include a locator **known to match**; an unaffected control reading zero means the probe is broken, not the product.
