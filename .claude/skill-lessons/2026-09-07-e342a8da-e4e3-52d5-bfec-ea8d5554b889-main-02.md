# .claude/agents/investigator.md — "do we have a test for X?" must search open PR branches, not only main

- Added: 2026-09-07
- Applies to: target only
- Evidence: Asked in Slack whether a Playwright test existed for a dashboard, the answer was produced by searching `origin/main` and the current working branch only, and reported that none existed. A reviewer then quoted a passing Playwright test for that exact dashboard by file path and tag; it lives on an unmerged branch belonging to another open PR, so both searches were correct and the answer to the question was still wrong.
- Proposed change: When answering whether coverage exists, state the ref the answer is true for, and check the open PRs' head branches (`git ls-tree` per branch, or a code search across the repo rather than one ref) before saying no test exists -- migrations and new suites commonly sit on an unmerged branch for weeks.
