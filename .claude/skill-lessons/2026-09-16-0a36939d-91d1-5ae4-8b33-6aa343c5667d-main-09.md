# .claude/agents/investigator.md — recurrence: "consistent, not a flake" asserted from three runs, refuted by the fourth

- Added: 2026-09-16
- Applies to: .claude/agents/investigator.md
- Evidence: Second occurrence in one session of the lesson in entry -03. A test that failed in three independent nightly runs was reported as "consistent across three runs, definitively not a flake"; a fourth run examined minutes later had passed the same test, making it 3 of 4. The claim was made from the runs already in hand, without enumerating the other runs of the same workflow that were sitting in the same listing.
- Proposed change: Make the rule mechanical rather than advisory — before characterising a failure's frequency in either direction, enumerate every completed run of that workflow in the window and state the ratio (n of m runs), never a bare "consistent" or "flaky".
