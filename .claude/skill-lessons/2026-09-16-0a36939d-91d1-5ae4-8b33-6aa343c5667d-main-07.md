# .claude/agents/investigator.md — the per-job log endpoint needs no token on a public repo

- Added: 2026-09-16
- Applies to: .claude/agents/investigator.md
- Evidence: The file describes `https://api.github.com/repos/<owner>/<repo>/actions/jobs/<job_id>/logs` as needing authenticated `curl`, so a session without a token falls back to `get_job_logs` with `tail_lines` — which again returned only post-job cleanup and no failure. The same URL fetched unauthenticated returned HTTP 200 and the whole 528 KB log, for a completed job inside a run still in progress, greppable at zero context cost.
- Proposed change: Drop the "authenticated" qualifier for public repositories and make that endpoint the first choice for one job's log, noting it works while the run is still in progress (unlike the run-logs zip, which 404s until the run ends).
