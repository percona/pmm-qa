# .claude/skills/fb-tests/SKILL.md — the job-log recipe's `gh api --allow-escape-sequences` flag does not exist in gh 2.96.0

- Added: 2026-09-23
- Applies to: fb-tests "Redirecting a job-log fetch" recipe, and any skill that fetches Actions job logs with gh
- Evidence: `gh api --allow-escape-sequences repos/percona/pmm-qa/actions/jobs/<id>/logs` failed with "unknown flag" on gh 2.96.0 (hidden by a `2>/dev/null`, so the first symptom was a 0-line log); plain `gh api repos/.../actions/jobs/<id>/logs > file` returned the full 1182-line log, and the `sed` escape strip worked on it.
- Proposed change: Drop the flag from the recipe (or guard it: `gh api --help | grep -q allow-escape-sequences`), and say that a redirected job-log fetch should keep stderr visible so an unknown flag isn't mistaken for an empty log.
