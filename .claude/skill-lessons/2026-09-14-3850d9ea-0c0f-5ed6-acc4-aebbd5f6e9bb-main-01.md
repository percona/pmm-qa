# CLAUDE.md (House style) — Never report a concrete value before reading it from its source

- Added: 2026-09-14
- Applies to: all skills and agents that report provisioned credentials, URLs, IPs or versions
- Evidence: A provisioning summary stated an admin password that had never been read from `provision.json`; the real value came back from `jq -r .passwords.pmm_admin_password` on the next tool call, forcing a correction in the following message.
- Proposed change: Add a House style rule that any credential, URL, IP, host or version quoted to the user must come from a read performed in the same turn that quotes it — read first, then report, never report and verify afterwards.
