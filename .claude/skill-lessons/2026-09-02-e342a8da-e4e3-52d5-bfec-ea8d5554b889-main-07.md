# .claude/agents/investigator.md — dedup must read the diff of any open PR touching the same area, not just its body

- Added: 2026-09-02
- Applies to: target only
- Evidence: The dedup step ("read each PR's title + body") flagged an open pmm-qa PR whose branch was named after the exact dashboard panels under investigation, but whose body described only unrelated user/role setup, so it was cleared and a fix was built and merged-ready. A reviewer later revealed that the same PR's diff also contained a background chunk-activity generator solving the same problem, written before the existing generator landed. The two changes touch different files, so git reports no conflict while both would run the same workload twice.
- Proposed change: In the dedup step, require reading the diff (not only title and body) of any open PR whose branch name, changed files, or reviewer history point at the same area, since a PR body often documents only part of its diff; and note that non-overlapping file sets are not evidence of non-overlapping behaviour.
