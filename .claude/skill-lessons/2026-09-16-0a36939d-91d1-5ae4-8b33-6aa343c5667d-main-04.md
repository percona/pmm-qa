# .claude/agents/investigator.md — an artifact carrying only server logs means no scenario ran

- Added: 2026-09-16
- Applies to: .claude/agents/investigator.md
- Evidence: A failing `@ssl-mysql` job's `artifacts_for_<tag>` bundle held `logs/` alone, with no `tests/output/` screenshots or traces; the job log later confirmed the failure was in a `BeforeSuite` hook, before any scenario started. The absence was readable from the artifact's file list, in one step, before any log was fetched.
- Proposed change: In the artifact-reading guidance, note that a bundle with no `tests/output/` entry is itself evidence the run died in a hook or setup rather than in a scenario — read the suite's hooks first instead of hunting for a per-test failure.
