# .claude/skills/jenkins-builds/SKILL.md — an error line in a console log does not identify the failing stage

- Added: 2026-09-19
- Applies to: .claude/skills/jenkins-builds/SKILL.md
- Evidence: a "cannot access ... No such file or directory" line was taken as the cause of five failing lanes and fixed as such, while the per-stage status showed that stage SUCCESS in every build; the real failure was two stages later, where both test workers reported OK yet the runner still exited non-zero.
- Proposed change: require reading the per-stage status to identify the stage whose status is FAILED before attributing a cause to any error text found in the console.
