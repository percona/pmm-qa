# .claude/skills/linode-ha-provisioning/SKILL.md — A teardown check must not run through credentials teardown just deleted

- Added: 2026-09-14
- Applies to: .claude/skills/linode-ha-provisioning/SKILL.md and .claude/skills/linode-docker-provisioning/SKILL.md
- Evidence: After teardown, the local kubeconfig was deleted and then an `until ! kubectl get --raw /readyz; do sleep 20; done` loop was run against that same `$KUBECONFIG`; it exited on the first iteration because the file was missing and was reported as "API server gone (cluster deleted)".
- Proposed change: In the Teardown section, state that cluster liveness must be confirmed before removing the kubeconfig (or through a path teardown does not invalidate, e.g. the relay or the external URL), and that a probe whose failure mode is indistinguishable from a missing credential is not evidence of deletion.
