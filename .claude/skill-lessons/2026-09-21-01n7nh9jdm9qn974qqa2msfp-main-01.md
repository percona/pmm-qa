# .claude/skills/linode-ha-provisioning/SKILL.md — build chart dependencies before installing pmm-ha from the clone

- Added: 2026-09-21
- Applies to: target only
- Evidence: The "swap in PMM-HA-GA" `helm upgrade --install pmm-ha /tmp/phc/charts/pmm-ha` failed with `found in Chart.yaml, but missing in charts/ directory: haproxy, pg-db, kube-state-metrics, prometheus-node-exporter`; a following `helm dependency build` failed with `no repository definition for https://haproxytech.github.io/helm-charts/, https://percona.github.io/percona-helm-charts/, https://prometheus-community.github.io/helm-charts`.
- Proposed change: Precede the swap's `helm upgrade` with `helm repo add` for haproxytech, percona and prometheus-community (`--force-update`) and `helm dependency build` in `charts/pmm-ha`, since a git clone carries no `charts/` tarballs.
