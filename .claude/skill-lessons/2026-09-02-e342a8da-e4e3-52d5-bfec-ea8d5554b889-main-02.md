# .claude/skills/linode-docker-provisioning/SKILL.md — the step 3 database command expands the password to empty

- Added: 2026-09-02
- Applies to: target only
- Evidence: The documented form assigns `ADMIN_PASSWORD=` and dereferences `"$ADMIN_PASSWORD"` inside the same simple command, so the dereference resolves before the assignment takes effect; `pgrep -af` on the box showed the framework running as `./pmm-framework --pmm-server-password  --client-version latest-tarball` with the password argument empty, and the run had to be repeated.
- Proposed change: Rewrite the step 3 example to pass the password literally or via `env VAR=... cmd --flag '<literal>'` rather than assigning and dereferencing the same name in one command, and add a `pgrep -af` check after launching to confirm the arguments actually carry the value.
