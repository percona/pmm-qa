# .claude/agents/investigator.md — a new test only counts as evidence once it has been shown to fail without the fix

- Added: 2026-09-08
- Applies to: .claude/agents/investigator.md
- Evidence: A fix's own bats test asserted `[[ $output == *'setup is working'* ]]`, which one occurrence satisfies, so a handler that dumped the first of two buffers and skipped the rest — exactly the regression the test existed to catch — stayed green; a reviewer caught it, and a one-line mutation to the handler then failed the corrected test where it had failed neither before.
- Proposed change: In the fix-verification step, require that a test written as the evidence for a fix be mutation-checked — break the fix, confirm the test fails, restore — before citing it, and prefer counting occurrences over substring matches when the claim is "every N were handled".
