# AGENTS.md — a step whose return value is captured cannot sit next to another `const` step

- Added: 2026-09-03
- Applies to: all `e2e_tests/` Playwright test authoring
- Evidence: Adding `const services = await pmmTest.step(...)` directly after `const baseline = await pmmTest.step(...)` in `e2e_tests/tests/ha/upgrade/helmUpgrade.test.ts` left an unfixable `Unexpected blank line before this statement @stylistic/padding-line-between-statements`; `--fix` answered with `ESLintCircularFixesWarning` because the config demands `blankLine: never` between two `const`s and `always` before a block-like statement. Moving the new step so both neighbours are `await` expression statements cleared it with no blank-line change.
- Proposed change: Note in the Playwright suite section that `padding-line-between-statements` in `e2e_tests/eslint.config.mjs` forbids a blank line between adjacent `const` declarations while requiring one around block-like statements, so a value-returning `pmmTest.step` must be placed where its neighbours are expression statements - the pair is unsatisfiable and `--fix` reports it as a circular fix.
