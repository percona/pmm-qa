# .claude/agents/investigator.md — a green CI job is not evidence its tests passed

- Added: 2026-09-18
- Applies to: all skills that read CI results
- Evidence: a nightly shard recorded results from the CodeceptJS report path while Playwright writes a different file, so `launchable record tests` raised FileNotFoundError every run, the gate passed an empty session, and shards with failing Playwright tests were reported green across eight lanes; the failures only surfaced when the job log's own test summary was read.
- Proposed change: before trusting a job's conclusion, confirm the report file the gate reads is the one the test framework writes, and cross-check the framework's own pass/fail summary in the log.
