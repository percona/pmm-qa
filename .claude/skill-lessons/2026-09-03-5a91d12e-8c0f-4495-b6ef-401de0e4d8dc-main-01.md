# AGENTS.md — the TypeScript lint entry point needs Node 22, so on Node 20 the commit gate cannot pass

- Added: 2026-09-03
- Applies to: all sessions and agents linting `e2e_tests/`
- Evidence: `npm run lint` in `e2e_tests` on Node v20.11.1 never reaches a file: eslint 10.9.1 aborts importing eslint-plugin-unicorn 74 with `TypeError: mapTypes.union is not a function`, and once the config loads the `stylish` formatter aborts with `TypeError: util.styleText is not a function` - both APIs are Node 22, which is what `.github/workflows/lint.yml` sets. `lint-changed.sh` runs that same `npm run lint` for any staged `.ts`, so the `PreToolUse` commit gate fails on Node 20 regardless of the diff.
- Proposed change: In the Linting section's `*.ts` row, state that the command needs Node 22 (`nvm use 22`) and that a Node 20 checkout fails at config load, not on findings - so "lint crashed" must never be read as "the diff is clean" or worked around by editing `eslint.config.mjs`.
