# .claude/skills/codeceptjs-migration/playwright-practices.md — An unused POM entry is not evidence; prefer the selector a green source test proves

- Added: 2026-08-24
- Evidence: `e2e_tests/pages/ha/settings.page.ts` already carried five locator entries with zero consumers, whose `text-input-*` testid convention was contradicted by the CI-green CodeceptJS source. MCP verification at the initial gate confirmed the source: the pre-existing testids matched 0 elements, the source-proven ones matched exactly 1. Because nothing consumed them, rewriting in place was a minimal-reuse diff rather than a breaking change. The reverse call was made for two toggle entries using a `switch-input-*` convention, which a second source POM independently attests and which MCP proved is a required strict-mode narrowing - the literal source selector matches 4 elements there.
- Proposed change: In `playwright-practices.md`, add: a POM entry with no consumers is unproven code, not a convention - when it disagrees with a currently-green source test, prefer the source-proven selector, verify both through MCP, and rewrite it in place; when a second source independently attests the existing convention, keep it and record why.
