# .claude/skills/codeceptjs-migration/branch-workflow.md — The pre-push commit check must use --first-parent

- Added: 2026-10-08
- Applies to: branch-workflow.md Tracker completion and cleanup, step 1
- Evidence: Row 32's tracker push ran `git log --oneline @{u}..HEAD`, which listed the allowed three commits (done, in-progress marker, main merge 7d061178) plus six origin/main commits that came in through the merge's second parent. The literal rule ("if it lists anything else, stop") would have blocked every row that merges main. The runner pushed after checking `--first-parent`, which was a judgement call the rule did not cover.
- Proposed change: Replace the check with `git log --oneline --first-parent @{u}..HEAD` (cross-check: `git log --oneline @{u}..HEAD ^origin/main`). Both must list only the done commit, this row's marker and the main merge.
