# .claude/skills/codeceptjs-migration/run.md — run cliHelper tests from Windows with ComSpec set to bash

- Added: 2026-10-13
- Applies to: run.md step 5 (local execution on the Windows host), any test whose `cliHelper.execute` command carries single quotes
- Evidence: Row 35 run 1 from Git Bash: PMM-T2014's `docker ps --filter 'name=^ps_pmm_gr_.*_1$'` failed with `invalid filter ''name'` because shelljs runs `cmd.exe` on Windows, which keeps single quotes. Linux CI uses `/bin/sh`, so the test is correct. Run 2 from PowerShell with `$env:ComSpec='C:\Program Files\Git\bin\bash.exe'` (process only) passed 5/5.
- Proposed change: In step 5, run Playwright on Windows with `ComSpec` pointing at Git bash for the process, so `cliHelper` commands are quoted as on the Linux runner. A cmd.exe quoting failure is tooling, not a migration failure.
