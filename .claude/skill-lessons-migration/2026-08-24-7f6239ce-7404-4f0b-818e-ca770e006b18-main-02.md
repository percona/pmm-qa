# .claude/skills/codeceptjs-migration/orchestration.md — Inspect local Docker resources in step 1, not step 2a

- Added: 2026-08-24
- Evidence: The fixed-resource inspection ("treat every matching resource as foreign... stop instead of adopting") lives in step 2a, after row selection, the `origin/main` merge, both graph refreshes, and the `in-progress` tracker commit. On a row-4 test run a foreign environment was found (pmm-server plus a three-node psmdb replica set and a MinIO container, up 9 hours) - a stop condition that was discoverable before any of that work, and which in a real run would have stranded a committed `in-progress` tracker row behind a blocked provision.
- Proposed change: Move the local-resource inspection into step 1's preflight, alongside the "another row in-progress" and "any migration PR open" stop checks, and leave step 2a to start provisioning only.
