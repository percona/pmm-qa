# .claude/skills/codeceptjs-migration/branch-workflow.md — review fixes on the publish branch have no local-pmm.sh and load .env with override

- Added: 2026-10-19
- Applies to: branch-workflow.md Tracker completion step 4-5 (review comments fixed with `git switch <branch>` in control's checkout) when a fix needs a local run
- Evidence: Row 39, after the final switch to `migrate-dashboards-verifyMysqlDashboards`, `bash .claude/scripts/local-pmm.sh up ...` failed with `No such file or directory`: `.claude/scripts/` exists only on control. `local-pmm.sh` derives `repo` from its own path, so a plain scratch copy points at the wrong tree. What worked: `git show CodeceptJS-migration:.claude/scripts/local-pmm.sh` into the scratchpad with `repo=` replaced by the literal checkout path. The branch's `playwright.config.ts` has `dotenv.config({ override: true })` and `e2e_tests/.env` sets `PMM_UI_URL` and `ADMIN_PASSWORD`, so `PMM_MIGRATION=1` does not protect the password; an untracked `playwright.config.mig-local.ts` with `override: false` beside the original, passed with `--config` and deleted after, kept it.
- Proposed change: In Tracker completion step 4, add the two commands: the pinned scratch copy of `local-pmm.sh` (`git show` plus `sed` on `^repo=`) and the untracked `override: false` config copy, both removed after the run.
