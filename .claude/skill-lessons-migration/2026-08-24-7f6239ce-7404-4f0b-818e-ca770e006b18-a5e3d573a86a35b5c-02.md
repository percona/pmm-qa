# .claude/skills/codeceptjs-migration/run.md — A migrated tag new to e2e_tests obliges a README regeneration in the writer phase

- Added: 2026-08-24
- Evidence: Row 4 carried `@grafana-pr`, a tag that had never appeared under `e2e_tests`. The repository's README generator check went stale the moment the migrated file landed, and that check is repo-wide, so it would have failed every later gate rather than only the publish step. The writer regenerated `e2e_tests/README.md` (one added line) inside its own phase, and static validation stayed clean through both gates.
- Proposed change: In `run.md` step 2, add to the writer's static validation: if any migrated tag does not already appear under `e2e_tests`, regenerate `e2e_tests/README.md` and re-run the generator's `--check` before returning `MIGRATION_READY`.
