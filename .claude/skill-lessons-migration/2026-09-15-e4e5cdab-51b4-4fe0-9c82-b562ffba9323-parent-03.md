# .claude/skills/codeceptjs-migration/orchestration.md - re-running a subagent's measurement inside the subagent's own scope is not independent verification

- Added: 2026-09-15
- Applies to: `.claude/skills/codeceptjs-migration/orchestration.md` ("A gate return without its evidence is not a verdict")
- Evidence: The final gate reported that the only in-repo mention of `nightly-e2e-tests-matrix.yml` was a doc comment in `.github/scripts/wait-for-gh-run.sh:13`. The parent confirmed it by grepping - with the same `-- .github/` scope the reviewer had used. Unscoped, the repository holds nine mentions (`AGENTS.md:58,94`, `docs/agents/AUTOMATIONS.md:67,68`, `.claude/agents/investigator.md:12,78`, `.claude/skills/qa-code-review/references/ci-workflows.md:7`, `wait-for-gh-run.sh:13`, `qa-integration/.../preflight.bats:88`). None is a caller, so the conclusion survived and the commit body was right - but the check confirmed only that the reviewer had run its own command correctly. The reviewer itself raised this, having just been caught by the same class of defect in a pathspec.
- Proposed change: In that section, state that when the parent verifies a gate finding, it widens the scope rather than reproducing the command: drop the path filter, drop the glob, count the whole repository and then explain the excess. A verification that cannot disagree with the claim is not evidence.
