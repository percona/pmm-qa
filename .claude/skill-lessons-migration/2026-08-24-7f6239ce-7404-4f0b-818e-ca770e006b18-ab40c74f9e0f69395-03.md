# .claude/skills/codeceptjs-migration/branch-workflow.md — Prove that newly-selected existing tests are executable, not merely selected

- Added: 2026-08-24
- Evidence: Row 4's coverage edit newly selected four existing tests in an unrelated Playwright file that no job selects today. The initial gate verified they were *selected*; the runner separately ran them against the provisioned environment (4 passed, 18.6s) and established they are *executable* there, needing no database at all. The distinction matters because the CI runner invokes the suite with a trailing `|| true`, so a newly-selected test that the job's environment cannot support fails silently and reads as flake rather than as a coverage defect introduced by the migration. The proof cost one 19-second run.
- Proposed change: In `branch-workflow.md` section Workflow coverage, add: when a coverage edit newly selects tests outside the migrated file, run those tests against the provisioned environment before committing the edit - selection evidence is not execution evidence, and the runner's `|| true` hides the difference.
