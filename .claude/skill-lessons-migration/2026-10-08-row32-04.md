# .claude/skills/codeceptjs-migration/branch-workflow.md — Dispatch the proof job with a grep scoped to the touched files

- Added: 2026-10-08
- Applies to: branch-workflow.md Attach CI execution (the dispatch for a nightly-only tag)
- Evidence: Row 32 dispatched `runner-e2e-tests-playwright.yml` with `pmm_test_flag='@qan'` and `setup_services='--database pgsql'`. `@qan` selects all 38 QAN tests across five files, and 13 failed for missing databases. The red check landed on the PR even though both migrated tests passed. The nightly shard can run them only because 5 shards share one server.
- Proposed change: Dispatch with a grep over the migrated titles plus every test in any target file the PR modified (ids with a trailing space, e.g. `'PMM-T128 |PMM-T193 '`). Check it with `--list --grep` so the count equals that file set exactly, and set `setup_services` to the union of databases those tests need: read each test for the services it filters on or `docker exec`s into (row 32: `pxc-dev` filter, `ps_pmm_` container), not only the migrated source's. The same union is what step 2a provisions locally, so local and CI run the same set (Kiran, 2026-10-09). Use the bare tag only when it selects nothing beyond those files.
