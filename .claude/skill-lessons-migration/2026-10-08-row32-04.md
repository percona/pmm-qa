# .claude/skills/codeceptjs-migration/branch-workflow.md — The dispatched runner must provision every database its selected tests need

- Added: 2026-10-08 (reworded 2026-10-09 per Kiran)
- Applies to: branch-workflow.md Attach CI execution (the `runner-e2e-tests-playwright.yml` dispatch), orchestration.md step 2a
- Evidence: For row 32 the parent dispatched the runner with `pmm_test_flag='@qan'` and `setup_services='--database pgsql'`, the migrated source's own setup. `@qan` selects 38 tests, and many need other databases (a `pxc-dev` service filter, a `ps_pmm_` container, MySQL and pg_stat_monitor services). 13 failed for missing databases, job 113582668012, and the PR showed a red check. The migrated tests themselves passed. The re-dispatch used `--database pgsql --database pxc --database ps` with the selection scoped to the touched files: 7/7 green on the first attempt, job 113650046818.
- Proposed change: Before dispatching, list what the flag selects (`npx playwright test --list --grep '<flag>'`). For each listed test, read the services it filters on, `docker exec`s into or registers. Set `setup_services` to the union of those databases, not the source's setup. If the union cannot run on one runner, narrow the flag to the migrated titles plus every test in a modified target file. Prove the narrowed list equals that set with `--list`. Provision the same union locally in step 2a, so the local run and CI cover the same tests on the same databases.
