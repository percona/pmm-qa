# .claude/skills/codeceptjs-migration/SKILL.md — PMM_MIGRATION does not protect a run on a branch cut from main

- Added: 2026-10-14
- Applies to: Review comments (fixes on the publish branch in control's checkout), any local Playwright run outside control
- Evidence: Row 36 review fix on `migrate-qan-details_explain_test`: that branch's `e2e_tests/playwright.config.ts` is main's, `dotenv.config({ override: true })`, so `.env`'s ADMIN_PASSWORD replaced `admin-password` despite `PMM_MIGRATION=1`. The writer's test run sent the wrong password, Grafana locked admin (36 blocked requests), and the parallel `ps,SETUP_TYPE=gr` registration failed with "Invalid username or password". Recovered by stopping the writer, 5 clean minutes, one `/v1/users/me` 200, then running with an untracked `e2e_tests/playwright.local-migration.config.ts` (`override: false`) via `--config`, deleted before commit. `.claude/scripts/` is also absent on that branch, so `local-pmm.sh` ran from a scratch copy with `repo=` pinned.
- Proposed change: In Review comments, say: on a publish branch, run Playwright with an untracked config copy beside the original setting `override: false` (house style), and run `local-pmm.sh` from control's copy; never start a test run before checking which `.env` override the branch's config applies.
