# .claude/skills/codeceptjs-migration/run.md — from Git Bash set uppercase COMSPEC, not ComSpec

- Added: 2026-10-14
- Applies to: run.md step 11 and step 5 when Playwright is launched from Git Bash on the Windows host
- Evidence: Row 36 runner: `export ComSpec=<bash.exe>` in Git Bash did not reach node; Git Bash already exports uppercase `COMSPEC=cmd.exe`, and node read `process.env.ComSpec` as `cmd.exe`, so PMM-T2014's `docker ps --filter 'name=...'` failed with `invalid filter ''name'`. With `COMSPEC="C:\Program Files\Git\bin\bash.exe"` the whole `details.test.ts` passed 10/10. The row 35 lesson worked only because it ran from PowerShell (`$env:ComSpec`).
- Proposed change: In run.md step 11 name both forms: PowerShell `$env:ComSpec='C:\Program Files\Git\bin\bash.exe'`; Git Bash `COMSPEC='C:\Program Files\Git\bin\bash.exe'` (uppercase).
