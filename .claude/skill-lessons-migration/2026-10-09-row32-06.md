- Added: 2026-10-09
- Applies to: orchestration.md step 3 (Wait for the environment and verify it), run-migration-single-test.sh --prepare-only
- Evidence: In row 32, `--prepare-only` reported ready (readyz 200, `/v1/users/me` 200) while pmm-agent in `pgsql_pgss_pmm_17` was disconnected with a 0-byte config. The initial gate spent about 17 min reloading an empty QAN page and returned REVIEW_FAILED on the environment. The parent's own data poll also measured nothing: `clickhouse-client` failed authentication inside a loop that treated a failure as "no data yet".
- Proposed change: After `--prepare-only`, check every provisioned container with `docker exec <c> pmm-admin status` (`Connected : true`) and `pmm-admin list` (every agent `Running`). For a QAN row, poll `POST /v1/qan/metrics:getReport` until `total_rows` is above the source's largest branch threshold, and record the count on the timeline. A poll's own command failure stops the loop with an error. It never counts as "no data yet".
