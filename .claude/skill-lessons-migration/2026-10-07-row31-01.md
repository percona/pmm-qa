# .claude/skills/codeceptjs-migration/SKILL.md — A CodeceptJS wait with no timeout has a 60 s floor

- Added: 2026-10-07
- Applies to: SKILL.md Waits and retries (budget order), audit-checklist.md timeouts
- Evidence: Row 31 T437 ported `I.waitForVisible(locator)` (no timeout; `pr.codecept.js:26` `waitForTimeout: 60000`) as a bare `toBeVisible()` at Playwright's 5 s default. Both review gates passed it; execution failed 2 of 2 on a slow QAN iframe, costing a writer loop and a third initial-gate attempt. On re-review the gate ruled the global default "not an explicit waiter", so the rule as written does not catch it.
- Proposed change: In the budget order, count a CodeceptJS wait with no timeout argument as an explicit waiter at `waitForTimeout` (60 s), and an action with none at the helper `timeout` (20 s). The reviewer checks every first wait in a test against it.
