# .claude/skills/codeceptjs-migration/graphify.md — Name the graph.json schema keys

- Added: 2026-08-24
- Evidence: The writer's first targeted filter over `graphify-out/graph.json` read the `edges` key and reported "edges 0", which reads like an empty or broken graph rather than a wrong key. The artifact is NetworkX node-link JSON: edges are under `links`, and each node's path is `source_file`, not `path`. `graphify.md` gives the file paths but not the schema, so the miss is guaranteed on the first attempt for anyone writing a targeted filter rather than using the query tools.
- Proposed change: In `graphify.md`, state that `graph.json` is NetworkX node-link JSON and name the two keys a targeted filter needs - `links` for edges and `source_file` for a node's path.
