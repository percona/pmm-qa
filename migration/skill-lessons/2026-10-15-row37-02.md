# .claude/skills/codeceptjs-migration/branch-workflow.md — dispatch flag must be artifact-name safe; WSL script paths from Git Bash

- Added: 2026-10-15
- Applies to: branch-workflow.md Attach CI execution (narrowed `pmm_test_flag`), orchestration.md step 2a (starting provisioning from Git Bash)
- Evidence: Row 37. A regex flag `PMM-T(...) .*@nightly @dashboards` listed exactly the 7 titles, but `runner-e2e-tests-playwright.yml` turns the flag into the upload-artifact name and `*` is invalid there; the id-alternation form (`'PMM-T2050 |PMM-T394 |...'`, run 38654020030 precedent) works. Separately, `wsl -d Ubuntu -- bash /mnt/c/...script.sh` from the Git Bash tool exited 127: Git Bash rewrote `/mnt/c/...` to `C:/Program Files/Git/mnt/c/...`; `MSYS_NO_PATHCONV=1` fixed it.
- Proposed change: In Attach CI execution, say the narrowed flag uses only ids with a trailing space and literal titles joined by `|`, never `*`, `(` or other artifact-name-invalid characters. In step 2a, say to prefix WSL calls from Git Bash with `MSYS_NO_PATHCONV=1`.
